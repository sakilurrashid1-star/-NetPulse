# 🌐 NetPulse — Network Intelligence Lab

**NetPulse** is an interactive, portfolio-grade networking laboratory built to make core networking concepts visual, explainable and hands-on.

## ✨ What it demonstrates

- 🗺️ Interactive network topology with client, routers, firewall, DNS, API and database nodes
- 📡 Simulated telemetry for latency, packet loss, throughput and packets/sec
- ⚡ Traffic burst and degraded-link scenarios
- 🧭 Traceroute simulation
- 🧮 CIDR / IPv4 subnet calculator
- 🤝 TCP three-way handshake visualization
- 🧱 OSI 7-layer explorer
- 🛡️ Network troubleshooting and security decision console
- 📱 Responsive dark interface with zero build dependencies

## 🧠 Networking concepts

The project connects practical networking ideas: IP addressing, routing tables, packet forwarding, TCP connection establishment, DNS, firewalls, transport/application protocols, latency, packet loss and throughput.

## 🚀 Run locally

No Node.js, Python server or package installation is required.

1. Clone the repository.
2. Open `index.html` in a modern browser.
3. Interact with the topology, traffic controls, subnet calculator, traceroute, handshake and OSI explorer.

## ⚠️ Scope

NetPulse is an **educational network simulation**, not a live packet monitor or replacement for Wireshark, tcpdump, SNMP or production observability systems. The telemetry values and routes are simulated for learning and portfolio demonstration.
