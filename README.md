# 🌐 NetPulse — Network Intelligence Lab

**NetPulse** is an interactive, portfolio-grade networking laboratory built to make core networking concepts visual, explainable and hands-on.

## ✨ What it demonstrates

- 🗺️ Interactive network topology with client, routers, firewall, DNS, API and database nodes
- 📡 Simulated telemetry for latency, packet loss, throughput and packets/sec
- ⚡ Traffic burst and degraded-link scenarios
- 🧭 Traceroute simulation
- 🧮 CIDR / IPv4 subnet calculator
- 🤝 TCP three-way handshake visualization
- 🧱 OSI 7-layer explorer
- 🛡️ Network troubleshooting and security decision console
- 💾 Local PCAP analysis and protocol fingerprinting
- 🧠 Advanced flow analytics, traffic timeline and relationship graph
- 🚨 Heuristic anomaly detection for scan-like, SYN-heavy, DNS and high-rate behavior
- 📤 JSON findings and CSV packet export
- 📱 Responsive dark interface with zero build dependencies

## 🧠 Advanced Network Intelligence Lab

Open the dedicated advanced analyzer:

The advanced module provides browser-local packet forensics for classic PCAP and basic PCAPNG captures, packet inspection, flow reconstruction, protocol fingerprints, source/destination relationship mapping, traffic timelines, searchable packet views and explainable heuristic findings.

## 🧠 Networking concepts

The project connects practical networking ideas: IP addressing, routing tables, packet forwarding, TCP connection establishment, DNS, firewalls, transport/application protocols, latency, packet loss, throughput, packet capture analysis and security investigation.

## 🚀 Run locally

No Node.js, Python server or package installation is required.

1. Clone the repository.
2. Open `index.html` for the core lab.
3. Open `advanced.html` for the advanced packet intelligence lab.

## ⚠️ Scope

NetPulse is an **educational network simulation and browser-local analysis lab**, not a live packet monitor or replacement for Wireshark, tcpdump, SNMP or production NDR/observability systems. Anomaly detection uses heuristic signals and should not be treated as a definitive security verdict. Packet data loaded into the advanced analyzer is processed locally by the browser.
